# Sportlens Uploader

Programm für Fotografen von [Sportlens Images](https://sportlens-images.de): Bilder verschlagworten (auch ohne Internet) und direkt hochladen.

**Download:** unter [Releases](../../releases/latest) – Mac (Apple-Chip oder Intel) oder Windows.

Anleitung und Zugang: im Sportlens Studio unter „Uploader“.
